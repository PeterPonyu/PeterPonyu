## About Me

2017 年高中毕业于**河北保定一中**，此后进入直博项目，攻读博士至今。

I graduated from **Baoding No.1 High School, Hebei** in 2017, and have since been enrolled in a direct Ph.D. program, pursuing my doctoral degree to this day.

My research focuses on building **machine learning methods for single-cell genomics** — spanning **scRNA-seq** and **scATAC-seq** — with emphasis on **cell fate decision modeling**, **interpretable latent representations**, **variational autoencoders**, **graph neural networks**, **hyperbolic geometry**, **neural ODEs**, and **flow matching**.

```text
🎓 Background     : 保定一中 (2017) → Direct Ph.D. program → Present
🔬 Current focus   : Decoding cell fate decisions from single-cell multi-omics
🛠️ Building        : 20+ open-source tools for single-cell representation learning
💡 Interests       : RL, VAE, Neural ODE, Flow Matching, Hyperbolic ML, Graph Learning
🤝 Open to         : Research collaboration, open-source tooling, reproducible analysis
```
