I build machine learning methods for **single-cell RNA-seq** and **single-cell ATAC-seq**, with a focus on **cell fate decision modeling**, **interpretable latent representations**, **variational autoencoders**, **graph neural networks**, and **neural ODEs**.

My recent work includes open-source methods and publications developed around **hematopoiesis**, **acute myeloid leukemia**, **irradiation recovery**, **lineage branching**, and **chromatin accessibility modeling**, including collaborations reflected in publications with **Army Medical University**.

## Selected publications

- **scRL** — *Biology* (2025)  
  [scRL: Utilizing Reinforcement Learning to Evaluate Fate Decisions in Single-Cell Data](https://doi.org/10.3390/biology14060679)  
  An actor–critic framework for identifying early fate-decision states and decoding developmental logic from single-cell data.

- **iVAE** — *BMC Biology* (2025)  
  [iVAE: an interpretable representation learning framework enhances clustering performance for single-cell data](https://doi.org/10.1186/s12915-025-02315-7)  
  An interpretable VAE framework designed to improve clustering and reveal correlated latent biological structure.

- **GNODEVAE** — *BMC Genomics* (2025)  
  [GNODEVAE: a graph-based ODE-VAE enhances clustering for single-cell data](https://doi.org/10.1186/s12864-025-11946-7)  
  Combines graph attention and neural ODEs for trajectory-aware single-cell representation learning.

- **scFocus** — *Computational and Structural Biotechnology Journal* (2025)  
  [scFocus: Detecting branching probabilities in single-cell data with SAC](https://doi.org/10.1016/j.csbj.2025.04.036)  
  Uses reinforcement learning to estimate branching probabilities and better characterize lineage structure.

- **CODE** — *Computers in Biology and Medicine* (2025)  
  [Correlated latent space learning for structural differentiation modeling in single cell RNA data](https://doi.org/10.1016/j.compbiomed.2025.111115)  
  Explores correlated latent space learning and continuum modeling for single-cell RNA data.
